\section{Introduction and Overall Architecture}
SysMon is a lightweight, terminal-free Unix system monitoring suite designed to collect, clean, analyze, and visualize operating system telemetry in real time. The system combines low-overhead Bash collectors, automated Python data cleaning and statistical forecasting, stateful threshold alerting, and a local web dashboard.
