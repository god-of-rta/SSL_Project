\begin{abstract}
SysMon is a lightweight, Unix telemetry monitoring, cleaning, analysis, and alerting platform designed for Linux environments. By polling Linux procfs and sysfs directly without invoking heavy runtime tools, SysMon maintains a minimal CPU probe footprint and bounded memory usage. This report documents the end-to-end design, data collection, automated statistical cleaning, multi-window analysis, RESTful backend architecture, and integration benchmarks across the entire software lifecycle.
\end{abstract}
